03 · Honest status

What builds today.

Existing features and next goals are clearly separated. Loader and version compatibility is never faked.

Available now

  • Create and edit Minecraft Java mod projects locally
  • Items and blocks with real, editable 16×16 textures
  • Generate Java/Gradle source and resources
  • Build Minecraft Java 26.2 with Fabric locally
  • Download the JAR and source archive from the build area
  • Windows app with Node.js, JDK and Gradle bundled

Coming next

  • Forge, NeoForge and Quilt as separate target adapters
  • Verified builds for more Minecraft versions
  • Recipes, entities, world generation and more content
  • Linux and macOS packages

Early alpha. Details in the project status and roadmap.
